# 聽字一般用戶體驗規格

文件版號 `0.3.0`。基線為 `main` 的 0.6.1「聽字・注音與語音輸入法」。本文件列出一般用戶從下載到日常使用時還缺的東西，並定義要補到什麼程度才算完成。它是待實作規格，不代表功能已存在。

## 對象與產品優勢

**對象**：會用記事本、瀏覽器和通訊軟體打中文，但不知道 Whisper、模型、Codex 或 TSF 是什麼的人。他們不會開命令列，也不會編輯設定檔。

**要守住並放大的優勢**：

1. **說完就插入，錯字當場用注音改。** 語音和注音在同一個產品裡，這是一般語音輸入工具沒有的。
2. **換欄不貼錯。** 錄音途中換了欄位，文字留在預覽，不會被打進錯的地方。
3. **可以完全在本機。** 錄音可以不離開電腦。

以下所有要求都不能破壞這三點。

## 現況盤點

以下依目前程式碼與發行包確認，不是推測。

| 環節 | 現況 | 一般用戶會卡住的地方 |
| --- | --- | --- |
| 取得 | GitHub 下載 ZIP；另需自行安裝 .NET 8 Desktop Runtime x64。 | 不知道要先裝 .NET，也不知道 ZIP 要完整解壓縮。 |
| 安裝 | 以系統管理員身分執行 `InstallTingzi.cmd`。 | 批次檔加 UAC 看起來不可信；程式未簽章，會被 SmartScreen 擋。 |
| 移除 | 執行 `RemoveTingzi.cmd`；Windows「應用程式」清單沒有本產品。 | 找不到正常的解除安裝入口。 |
| 語音（本機） | 需手動建立 `voice-root.txt`，指向 `whisper-v1.9.2` 與 `ggml-base.bin`；只用 CPU（`-ng`）。 | 沒有下載模型的入口，裝好後本機辨識不能用。 |
| 語音（線上） | 經第三方 `codex-asr`，需要 Codex 登入。 | 大多數人沒有 Codex 帳號，線上辨識也不能用。 |
| 注音 | 使用內建注音引擎與安裝包附的公開詞庫，裝好即可使用。整句選字的品質仍在調整。 | 長句的選字不夠準時，需要逐字改。 |
| 啟動 | 浮窗在切到輸入法時，或從開始功能表開啟；沒有登入時自動啟動的選項。 | 重開機後找不到麥克風。 |
| 設定 | 兩頁：「語音輸入」（麥克風、辨識方式、快捷鍵、預覽字級、完成後動作）與「注音與工具」。 | 沒有麥克風試錄；快捷鍵只能從固定組合加 A–Z 挑；看不出目前哪些功能真的能用。 |
| 系統匣選單 | 同時列出「啟用本機學習」「關閉本機學習」，以及「在 Codex 草稿按 Ctrl+Alt+V 貼入」。 | 開發用語和特定工具的說明混在一般選單裡。 |
| 更新 | 沒有檢查更新。 | 不知道有新版。 |
| 求助 | 錯誤訊息多為「無法開啟工具，請確認完整套件已安裝」一類。 | 不知道下一步該做什麼。 |

## 缺口與要求

每項標示優先順序：**P0** 沒有它一般用戶無法用；**P1** 能用但體驗明顯不足；**P2** 加分項。

### A. 取得、安裝與移除

**A1 單一安裝程式（P0）**

- 提供一個 `聽字-Setup-<版本>-x64.exe`，雙擊即可安裝。內含或自動取得 .NET 8 Desktop Runtime；缺少時以中文說明並提供一鍵安裝。
- 安裝畫面顯示產品名稱、圖示、版本、安裝位置與會註冊的輸入法。
- 從任何既有版本升級時保留輸入法 ID、偏好、快捷鍵、詞表、學習資料與 `voice-root.txt`，行為與現行升級器相同。
- **驗收**：在乾淨的 Windows 11 x64 上，不開命令列完成安裝；升級前後輸入法清單只有一個聽字，資料雜湊不變。

**A2 程式簽章（P0）**

- 安裝程式、文字服務 DLL 與浮窗執行檔都要有程式碼簽章，避免 SmartScreen「無法辨識的應用程式」警告。
- **驗收**：下載後首次執行不出現未知發行者警告；`Get-AuthenticodeSignature` 皆為 Valid。

**A3 Windows 應用程式清單（P0）**

- 在「設定 → 應用程式」顯示「聽字・注音與語音輸入法」，含版本、發行者、圖示與解除安裝。
- 解除安裝時先詢問是否保留個人資料（詞表、學習、設定），預設保留。
- **驗收**：從應用程式清單移除後，輸入法、捷徑與程式目錄都消失；選擇保留時 `%LOCALAPPDATA%\Tingzi` 仍在。

### B. 第一次啟動

**B1 首次設定流程（P0）**

安裝完成後自動開啟，三步內可以開始用：

1. **麥克風**：列出裝置，即時顯示音量條，可試錄三秒並播放。
2. **辨識方式**：說明本機與線上的差別（是否離開電腦、需要什麼帳號），只把確定可用的選項標為可選。本機模型尚未下載時，提供「下載建議模型」按鈕（見 C1）。
3. **練習一句**：在內建練習欄位錄一句，示範插入、改字（注音）與換欄保留預覽。

- 任何一步都可以略過，之後從設定再進入。
- 完成後提示錄音快捷鍵與右側麥克風位置。
- 本規格的 B1 是最小可用版；硬體偵測與多種模型的比較另行規劃。
- **驗收**：新使用者在不讀文件的情況下，五分鐘內完成第一次語音插入與一次注音改字。

**B2 登入時自動啟動（P1）**

- 設定提供「登入 Windows 時啟動語音浮窗」，首次設定預設開啟。
- **驗收**：重開機登入後右側麥克風出現，不需先切換輸入法。

### C. 語音辨識

**C1 一鍵取得本機模型（P0）**

- 不再要求手寫 `voice-root.txt`。程式內提供模型下載：顯示來源、大小、授權與雜湊，同意後下載、校驗、試跑，再切換使用。下載可取消、續傳，失敗回到上一個可用設定。
- 預設建議能在一般筆電 CPU 上跑的中文模型；有可用 GPU 時才提供加速選項，並實測後再標示。
- 既有 `voice-root.txt` 使用者升級後沿用原設定。
- **驗收**：在沒有任何 Whisper 檔案的電腦上，只透過介面完成模型下載並辨識一句中文。

**C2 不需要 Codex 的線上選項（P1）**

- 線上辨識不應只綁 Codex 登入。規格上保留辨識服務介面（`IRecognitionEngine`），新增可由使用者自行填入金鑰的服務，或由產品提供的服務；採用哪一種須另立決策，並寫明錄音去向與費用。
- 未設定線上服務時，線上選項顯示為「未設定」，不能選。
- **驗收**：沒有 Codex 的使用者能看懂線上辨識需要什麼，且不會誤選到無法使用的選項。

**C3 標點與常用詞（P1）**

- 辨識結果自動加入中文標點，可在設定關閉。
- 使用者可維護「常用詞與替換」清單（人名、專有名詞、錯字替換），在辨識後套用；只有使用者確認的條目才會生效。
- **驗收**：清單中的替換在本機與線上辨識結果都套用，且可預覽、刪除、匯出。

**C4 辨識紀錄（P2）**

- 浮窗提供最近 20 句紀錄，可再次複製或插入。只存在本機，可一鍵清除，可在設定關閉。
- **驗收**：關閉紀錄後不寫入任何辨識文字到磁碟。

### D. 注音

**D1 整句選字品質（P1）**

- 內建引擎已是唯一的注音引擎。下一步是提升長句的斷詞與選字：比對兩種斷詞模式、補鄰接規則、調整詞頻權重。
- 詞庫只使用公開授權來源，來源與雜湊記錄在 `windows/standalone-data/provenance.json`。
- **驗收**：準備一組常用句子，記錄整句一次選對的比例，每次調整後重跑並不得退步。

**D2 注音狀態看得懂（P1）**

- 設定的「注音與工具」改為狀態卡：斷詞模式、學習是否開啟、詞表筆數與來源。
- 學習開關改為單一切換，系統匣不再同時列出「啟用」與「關閉」。
- **驗收**：使用者從設定頁能回答「現在是誰在處理注音、學習有沒有開」。

### E. 設定與介面

**E1 設定頁重整（P1）**

- 分為「一般」「語音」「注音」「隱私」「關於」五個區塊。「一般」放登入啟動、快捷鍵、預覽字級與外觀；「關於」放版本、檢查更新、授權與回報問題連結。
- 快捷鍵改為「按下想用的組合」錄製，偵測衝突時說明被誰占用並建議替代。
- 預覽字級改為滑桿或更多級距，並跟隨 Windows 文字大小設定。
- **驗收**：每個設定項目都有一句白話說明；鍵盤可完整操作；150% 與 200% 縮放下沒有截字。

**E2 系統匣選單精簡（P1）**

- 一般選單只留：開始／停止錄音、顯示浮窗、最近一句（複製／編輯）、設定、結束。
- 「辨識本機音檔」「用同一段錄音改跑本機」「捨棄這段錄音」只在有對應狀態時顯示。
- 特定工具的提示（例如 Codex 草稿貼入）移到說明頁，不放在選單。
- **驗收**：選單在待命狀態不超過 6 項，且沒有停用的說明文字項目。

**E3 外觀一致（P2）**

- 支援 Windows 深色模式；浮窗、設定、候選窗與輸入行使用同一套品牌色（橫耳鍵靛色）。
- 浮窗上的錄音、處理中、完成、錯誤狀態有一致的圖示與顏色，並有文字或螢幕報讀名稱，不只靠顏色。
- **驗收**：亮色與深色下對比度符合 WCAG AA；螢幕報讀程式能讀出浮窗狀態。

### F. 錯誤、求助與更新

**F1 錯誤訊息有下一步（P1）**

- 每則錯誤說明發生什麼、使用者可以做什麼，並提供對應按鈕（例如「選擇其他麥克風」「下載模型」「改用本機辨識」）。
- 不在訊息中顯示內部檔名，例如 `TingziKeyboard.exe`。
- **驗收**：列出所有錯誤訊息，每則都有可執行的下一步。

**F2 回報問題（P2）**

- 「關於」頁提供「回報問題」：自動帶入版本、Windows 版本與辨識模式，預覽後由使用者決定送出；不附錄音、詞表或完整使用者路徑。
- **驗收**：產生的回報內容通過與 `package_release.py` 相同的本機路徑掃描。

**F3 檢查更新（P1）**

- 啟動時（每天至多一次）檢查 GitHub Releases，有新版時在浮窗與設定提示，顯示更新重點，使用者同意才下載安裝。可在設定關閉。
- **驗收**：關閉檢查後不發出任何網路請求；更新後資料保留規則同 A1。

### G. 隱私

**G1 隱私頁（P0）**

- 在設定的「隱私」區塊以白話說明：本機模式錄音不離開電腦；線上模式錄音會送到哪個服務；辨識紀錄、學習資料與詞表存在哪裡；如何全部刪除。
- 提供「刪除所有個人資料」按鈕，刪除前列出將刪除的項目。
- 第一次選用線上辨識時明確同意一次，之後可在隱私頁撤回。
- **驗收**：從未同意線上辨識的使用者，任何情況下錄音都不會送出電腦。

## 優先順序與分期

| 階段 | 內容 | 完成時一般用戶可以 |
| --- | --- | --- |
| 1 | A1、A2、A3、D1、C1、G1 | 下載一個安裝檔，裝好就能用本機語音和注音，知道錄音去向。 |
| 2 | B1、B2、D2、E1、E2、F1、F3 | 不讀文件也能完成設定，重開機後照常使用，遇到錯誤知道怎麼辦。 |
| 3 | C2、C3、C4、E3、F2 | 依習慣調整辨識結果與外觀，回報問題更容易。 |

每階段結束時發行一個候選版，在乾淨 Windows 與既有安裝的升級兩種環境驗收，並記錄 commit、版號、測試環境與結果。

## 界線

- 不散布其他廠商的輸入法程式、詞庫或資料庫，執行時也不呼叫它們。
- 不自動切換到線上辨識，不自動上傳錄音、詞表或紀錄。
- TSF 識別、安裝目錄與資料位置依[產品識別](tingzi-product.md)，變更時須有升級搬遷方案。
- 全庫授權、程式簽章憑證與發行管道由維護者決定，本規格只定義需求。
