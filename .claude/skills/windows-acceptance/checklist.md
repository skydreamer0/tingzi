# Windows 實機驗收清單

依這次變更挑相關的分組，不必每次全做。每一項都用自造的文字。

## 基本（每次發行前）

- [ ] 全新安裝：執行 `Tingzi-Setup-<版本>-x64.exe`，完成後「設定 > 應用程式」出現「聽字・注音與語音輸入法」。
- [ ] 安裝後按 Windows＋空白鍵，鍵盤清單有「聽字・注音與語音輸入法」。
- [ ] 從上一個正式版升級：設定、錄音快捷鍵、自訂詞與學習資料都保留，浮窗自動開啟新版。
- [ ] 同一版再安裝一次（修復）不會出錯。
- [ ] 移除：詢問是否刪除個人資料，選保留時 `%LOCALAPPDATA%\Tingzi` 仍在。
- [ ] 設定「關於」頁顯示正確版號。

## 注音輸入法

- [ ] 在記事本、瀏覽器網址列與 Word 打一句注音並選字。
- [ ] 自訂詞新增後能打出來。
- [ ] 簡繁切換正常。

## 語音浮窗

- [ ] 「語音」頁的麥克風「測試」音量條會動。
- [ ] 在記事本按錄音快捷鍵說一句，停止後文字插入原位置。
- [ ] 錄音中改點另一個欄位：文字不自動插入，浮窗展開顯示結果。
- [ ] 每種要驗收的辨識方式（本機 Whisper、Codex 線上辨識、自選線上服務）各試一次。
- [ ] 錄音太短時不送出辨識。

## 安裝與更新

- [ ] 「關於」頁按「立即檢查」能找到比目前新的正式 release。
- [ ] 「下載並安裝」核對 SHA-256 後啟動安裝，裝好後開啟新版。
- [ ] 開啟「自動更新」時，背景下載後才詢問；錄音中不詢問。
- [ ] 缺少 WebView2 Runtime 的電腦，安裝程式會自動安裝。

## AI 潤稿

- [ ] 在「語音」頁填入服務網址、模型與金鑰後，口說一段含改口的句子，貼入的是整理過的文字。
- [ ] 浮窗說明這一則是否經過潤稿與花費時間。
- [ ] 少於 8 個字不送出；潤稿多出數字或否定詞時改用原文。
- [ ] 關閉潤稿或依程式停用時不送出。
