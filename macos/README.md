# 聽字・語音輸入｜macOS（預覽）

macOS 版只有語音輸入：螢幕邊緣的聽字圖示、錄音、辨識、把文字貼回原本的程式，以及設定頁。注音輸入法是 Windows 的文字服務，macOS 版沒有；打注音請用 macOS 內建的注音輸入法。

**目前狀態：** 還沒有在 Mac 上實際執行驗收。編譯、測試與打包由 GitHub Actions 的 macOS 工作流程執行。自 0.10.0 起，[Releases](https://github.com/skydreamer0/tingzi/releases/latest) 會附上磁碟映像檔 `Tingzi-<版本>-macos.dmg`；0.9.0（含）以前沒有提供磁碟映像檔，可自行建置。

## 安裝

需要 macOS 11 以上，Apple 晶片與 Intel 的 Mac 都能用。

1. 從 [Releases](https://github.com/skydreamer0/tingzi/releases/latest) 下載 `Tingzi-<版本>-macos.dmg`。
2. 想確認檔案完整時，在「終端機」執行 `shasum -a 256 ~/Downloads/Tingzi-<版本>-macos.dmg`，結果要和同一頁的 `.sha256` 檔一樣。
3. 打開下載的檔案，會出現一個視窗，把「Tingzi」拖到旁邊的「應用程式」資料夾，再在 Finder 側邊欄按「聽字」旁的退出鈕。
4. 到「應用程式」資料夾打開「Tingzi」。

**第一次開啟被擋下時：** 聽字沒有 Apple 的開發者簽章，也沒有經過 Apple 公證，第一次開啟時 macOS 會說無法確認它沒有惡意軟體。

- macOS 15 以後：先按「完成」，到「系統設定 > 隱私權與安全性」，在「安全性」一段找到聽字被阻擋的訊息，按「強制打開」，輸入密碼後再按「打開」。在 Finder 按右鍵選「打開」已經不能略過這個檢查。
- macOS 14 以前：在 Finder 對「Tingzi」按右鍵選「打開」，再按「打開」。

允許一次之後，之後開啟就不會再問。

**更新：** 下載新版的磁碟映像檔，同樣把「Tingzi」拖到「應用程式」資料夾，選「取代」。設定、自訂詞與學習資料存在個人資料夾，不會受影響。因為沒有開發者簽章，更新後 macOS 可能再問一次麥克風和輔助使用權限；如果「輔助使用」裡聽字已經打開卻還是不能貼入，把它從清單移除（按「−」）再重新加入。

**移除：** 結束聽字（選單列圖示 > 結束），把「應用程式」裡的「Tingzi」丟到垃圾桶。要一併刪掉設定與自訂詞，再刪除 `~/Library/Application Support/Tingzi`；開過「登入時啟動」的話，也刪除 `~/Library/LaunchAgents/app.tingzi.voice.plist`。

## 建置

需要 macOS 11 以上、Rust（stable）、Python 3 與 Xcode 命令列工具。在儲存庫根目錄執行：

```bash
bash macos/build.sh
```

需要用 rustup 安裝的 Rust，腳本會加入 Apple 晶片與 Intel 兩種目標。完成後會有 `.build/macos/Tingzi.app`，以及同一個資料夾裡的磁碟映像檔 `Tingzi-<版本>-macos.dmg` 和它的 `.sha256`。程式同時支援兩種 Mac，但只做了本機簽章，沒有 Developer ID；拿到別台 Mac 上第一次開啟時，照上面「第一次開啟被擋下時」的步驟允許。`bash macos/check_dmg.sh .build/macos/Tingzi-<版本>-macos.dmg` 會檢查磁碟映像檔的內容、雜湊與簽章。

只想跑測試或開發版：

```bash
cargo test --manifest-path app/src-tauri/Cargo.toml
```

```bash
cargo run --manifest-path app/src-tauri/Cargo.toml
```

## 第一次使用

1. 開啟 `Tingzi.app`。它是選單列程式，不會出現在 Dock；選單列和螢幕邊緣各有一顆聽字圖示。 可把浮窗圖示拖到螢幕左側或右側；編輯區與浮條會往圖示所在的一側收合。
2. 第一次錄音時，macOS 會詢問是否允許使用**麥克風**。
3. 第一次要把文字貼回其他程式時，macOS 會要求**輔助使用**權限（系統設定 > 隱私權與安全性 > 輔助使用）。允許之前，文字只會複製到剪貼簿並留在浮窗，自己按 Command＋V 貼上。
4. 重新建置或更新到新版後簽章會改變，macOS 可能再問一次這兩項權限。
5. 第一次在這台 Mac 開啟時，設定視窗會帶你選麥克風、選辨識方式，並在文字編輯裡練習一句。每一步都可以略過，之後可以在「關於」頁按「首次設定」重來。
6. 選的麥克風沒接上或打不開時，聽字會改用 macOS 預設的麥克風錄音，浮條在錄音時間上方註明改用了哪一支；接回來後，下一次錄音會自動用回它。

## 和 Windows 版不同的地方

| 項目 | macOS |
| --- | --- |
| 錄音快捷鍵 | 預設 Control＋Option＋R；在設定按「變更」後按下想用的組合，字母或數字要搭配 Control、Option 或 Command，F1 到 F24 可以單獨使用 |
| 再貼一次上一則 | Option＋Shift＋Z |
| 貼入方式 | 一律經剪貼簿送出 Command＋V |
| 換了地方就不貼 | 以「程式」判斷：錄音途中切到別的程式就不貼入。同一個程式裡換視窗或換欄位無法分辨，文字會貼到目前游標所在的地方 |
| 依程式設定 | 程式以應用程式名稱比對，例如 `Safari.app` |
| 貼入 Codex 草稿（Control＋Option＋V） | 鍵盤在 Codex 桌面版的任何欄位都會貼入，不分訊息框或搜尋框 |
| 自選服務的金鑰 | 存在登入鑰匙圈 |
| AI 潤稿的金鑰 | 存在登入鑰匙圈，和自選服務的金鑰分開 |
| 登入時啟動 | 在 `~/Library/LaunchAgents/app.tingzi.voice.plist` 寫一個啟動項目 |
| 個人資料 | `~/Library/Application Support/Tingzi` |
| 回報問題 | 和 Windows 版一樣在「關於」頁或選單列選單按「回報問題…」；操作記錄是個人資料夾裡的 `tingzi-log.txt` |
| 檢查更新 | 和 Windows 版一樣在「關於」頁檢查與提示，但不會自動安裝；按「開啟下載頁」下載新的磁碟映像檔，照上面「更新」的步驟換掉 |
| 注音頁 | 只留下自訂詞；鍵盤配置、文字範本、本機學習等注音輸入法的項目不顯示 |

## 邊講邊出字

在設定的「語音」頁選擇「Codex 線上辨識」後，可以開啟「邊講邊出字」實驗功能。錄音中每次停頓，剛說完的那一句會經 Codex 傳到 ChatGPT 辨識，辨識好就直接打進錄音開始時游標所在的欄位，例如聊天視窗的輸入框，不必等到停止錄音。

- 錄音途中切換到別的視窗，聽字就不再打字；還沒打進去的句子留在浮條，停止錄音後顯示在預覽並複製到剪貼簿。
- 錄音快捷鍵還按著的時候（「按住說話」），多數程式要等放開才收得到字，這段時間句子先顯示在浮條。想要邊講邊進字，請用按一下開始、再按一下停止的方式。
- 開著「AI 潤稿」，或「辨識完成後」選的不是「自動插入並複製文字」時，句子只顯示在浮條，停止錄音後才依設定處理全文。
- 逐句打進去的文字不會經過 AI 潤稿；個人詞彙與取代規則是一句一句套用的。取消錄音時，已經打進去的句子不會收回。
- 浮條若顯示「停止錄音後會辨識還沒出字的部分」，表示有一句沒辨識成功，聽字會在停止後把剩下的錄音一次辨識完再補上。

## 本機 Whisper

1. 安裝 whisper.cpp 的命令列工具，例如 `brew install whisper-cpp`，會得到 `/opt/homebrew/bin/whisper-cli`。也可以把 `whisper-cli` 放進 `~/Library/Application Support/Tingzi/whisper/`。
2. 到設定的「語音」頁選「本機 Whisper」，在模型清單按「下載」。下載前會列出來源、大小與授權，下載後核對檔案並試跑一次。自己準備的模型檔（檔名是 `ggml-<名稱>.bin`）也可以放進 `~/Library/Application Support/Tingzi/whisper/downloads/`。
3. 要用顯示卡辨識，開啟同一頁的「顯示卡加速」；`whisper-cli` 本身就支援，不必另外下載。

## AI 潤稿

選用，預設關閉，用法和 Windows 版相同：在設定的「語音」頁填入 OpenAI 格式的服務網址、模型名稱與金鑰，按「測試」試試，再打開開關。開啟後，辨識出的文字（不是錄音）會連同自訂詞和「補充說明」送到這個服務；網址是 `localhost`（例如 Ollama）時文字留在這台 Mac。服務出錯時照常貼入原文。每次口述完成時，浮條會註明這一句有沒有潤稿；浮窗的「最近紀錄」可以取回潤稿前的文字來比較。潤稿結果多出原文沒有的數字或否定的字時，改用原文。「輸出語言」可以選英文或繁體中文，「依程式設定」也能替個別程式選輸出語言和潤稿語氣。打開「用語音改寫選取的文字」後，選取文字、按 Control＋Option＋E 說出要怎麼改，再按一次，選取的文字就換成改寫的結果；這需要在「系統設定 > 隱私權與安全性 > 輔助使用」允許聽字。

## 還沒做的事

- 在實機上驗收錄音、三種辨識方式、AI 潤稿、貼入、快捷鍵、選單列選單與設定頁。
- Developer ID 簽章與公證；目前其他 Mac 開啟時會看到 Gatekeeper 警告。
- 應用程式圖示目前由 256 px 的圖放大，之後換成完整尺寸的圖示。
- 在設定頁直接下載並安裝新版。
