# 聽字品牌素材

<img src="tingzi.svg" width="80" height="80" alt="淡靛色鍵帽中橫放完整的耳字">

「橫耳鍵」是聽字的產品圖示。完整的「耳」順時針放倒，兩道內筆留在鍵帽中央。小尺寸版本保留六筆，將筆畫對齊像素。

| 使用位置 | 檔案 |
| --- | --- |
| README、文件、可縮放的大圖 | [主稿 SVG](tingzi.svg) |
| 16 像素的介面圖示 | [16 px SVG](tingzi-16.svg) |
| Windows 程式與通知區 | [多尺寸 ICO](tingzi.ico)，內含 16、20、24、32、48、64、128、256 px |

Windows 建置與打包沿用 `windows/tingzi.ico`、`windows/tingzi.svg`。更新品牌素材時，將對應檔案同步到這兩個位置，並確認 SHA-256 相同。工作列用橫耳鍵識別程式；浮窗上的麥克風按鈕維持錄音用途。
