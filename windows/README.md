# 聽字・注音與語音輸入法 0.10.0｜Windows

## 安裝及第一次使用

需要 x64 Windows。下載 `Tingzi-Setup-<版本>-x64.exe`，雙擊後依畫面安裝；安裝程式會要求系統管理員權限。語音浮窗使用 Microsoft Edge WebView2 Runtime，Windows 11 已內建，大多數 Windows 10 電腦也已經有；沒有的話，安裝程式會自動從微軟下載安裝；網路連不上時聽字照樣裝好，注音可以先用。不必再安裝 .NET。安裝程式也會把聽字加進你的鍵盤清單（缺少「中文（台灣）」時一併加入），裝好後按 Windows＋空白鍵就能選到；同一台電腦的其他使用者第一次開啟語音浮窗時，也會自動加入。萬一清單裡沒有，到「設定 → 時間與語言 → 語言與地區」，在「中文（台灣）」的「語言選項」按「新增鍵盤」選「聽字・注音與語音輸入法」，或在系統匣選單按「切換到注音輸入法」。安裝記錄寫在 `%TEMP%` 裡名為「Setup Log <日期>」的文字檔，裝不起來時可以附上這個檔回報問題。

在安裝精靈按下「安裝」後，畫面會顯示目前步驟，例如解開安裝檔、複製程式檔並註冊注音輸入法，或加入鍵盤清單。動畫表示作業正在進行，不顯示百分比。接受自動更新提示後，只會看到一般的安裝進度視窗，不會列出這些步驟。

要在多台電腦上不經畫面安裝（例如由管理員派送），在系統管理員的命令提示字元執行 `Tingzi-Setup-<版本>-x64.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART`。結束碼 0 表示成功；其他數字表示沒有裝好，原因寫在 `/LOG="路徑"` 指定的記錄檔。

已經裝過聽字時，執行新版的安裝程式就是升級；同一版再執行一次會重新安裝，修復被改動或損壞的程式檔。開著的語音浮窗會先關閉，裝好後自動開啟新版。要移除時，到「設定 → 應用程式 → 已安裝的應用程式」找「聽字・注音與語音輸入法」，按「解除安裝」；過程中會詢問是否一併刪除個人資料（偏好、自訂詞、學習資料、辨識紀錄與已下載的模型），預設保留。保留時，程式目錄裡的本機詞表與 `voice-root.txt` 會另外複製到 `%LOCALAPPDATA%\Tingzi\kept-after-uninstall`。

安裝完成後，按 Windows 鍵搜尋「聽字」，即可在同一個視窗開啟「語音輸入」與「注音與工具」。

發行版只提供安裝程式。自行從原始碼建置的 ZIP 要在解壓縮目錄以系統管理員身分執行 `InstallTingzi.cmd` 安裝，移除時執行安裝目錄裡的 `RemoveTingzi.cmd`；這種方式不會出現在應用程式清單，步驟見[開發指南](../docs/development/README.md)。

第一次在這台電腦開啟時，設定視窗會帶你走三個步驟：選麥克風並測試收音、選辨識方式（選本機時直接下載建議的模型），以及在記事本裡口述一句、用注音改一個字。每一步都可以略過；之後想重來，到設定的「關於」頁按「首次設定」。從舊版升級的人不會看到這些步驟。

在「語音」設定點選引擎圖示；「使用中」顯示實際套用的引擎。Claude 尚未接通，錄音或辨識期間不能切換。

升級會沿用同一個 Windows 輸入法、偏好設定、錄音快捷鍵、自訂詞、文字範本、學習資料與本機詞表。升級前就開著的程式（例如瀏覽器、通訊軟體、檔案總管）還會用舊版的注音，把它們關掉再開，或登出 Windows 再登入，就會換成新版。升級後若收音的麥克風不對，請到設定重新選一次。Windows 的輸入法清單可用 Windows＋空白鍵開啟，名稱為「聽字・注音與語音輸入法」。

## 找回浮窗

平常啟動時，螢幕工作區最右側只顯示聽字圖示（橫耳鍵標誌）。先點一下要輸入文字的欄位，再點右側的圖示開始講；圖示變成停止鍵時再點一次結束。辨識完成且已在原欄位插入時，右側維持小圖示。換欄位或遇到辨識錯誤時，浮窗會展開，顯示結果或原因；沒有插入的文字會出現在浮窗裡可以修改的編輯區。文字已經插入、編輯區卻因為剪貼簿被其他程式改過而展開時，放著不動 8 秒後會自動收起；滑鼠停在浮窗上、正在打字或選「最近紀錄」時不會收起。

拖曳圖示可調整高度，也可以移到螢幕另一側。在圖示上按右鍵會展開完整浮條；按「收合成圖示」，浮條與編輯區會往圖示所在的一側收回。

在**開始功能表搜尋「語音浮窗」**，或在系統匣圖示上按右鍵選「顯示／找回浮窗」。待命時浮條顯示在滑鼠所在的螢幕。按浮條右側的設定鍵，或在系統匣選單選「開啟設定…」，會開啟設定視窗，共有「一般」、「語音」、「注音」、「隱私」和「關於」五頁。在「語音」頁的麥克風旁按「測試」，對著麥克風說話時下方的音量條會跟著動，十秒後自動停止。設定左側是分頁導覽，每個設定項目旁有一句說明。每項設定改了就立刻套用，不需要另外儲存；按「關閉」或 Esc 可關閉設定。

## 語音輸入

1. 在設定的「語音」頁選擇麥克風和辨識方式。選的麥克風沒接上或打不開時（例如藍牙耳麥還沒連上），聽字會改用 Windows 預設的麥克風錄音，浮條在錄音時間上方註明改用了哪一支；選的麥克風接回來後，下一次錄音會自動用回它。錄音途中若麥克風斷線，浮條會提示，並辨識斷線前已錄到的語音。沒有可辨識的內容時，浮條會顯示錯誤。線上辨識（Codex）使用第三方的非官方元件 codex-asr，沿用這台電腦上 Codex 的 ChatGPT 登入，將該次錄音交給 ChatGPT 辨識。這不是 OpenAI 提供或支援的功能，OpenAI 調整服務時可能無法使用；需要穩定運作時，請改用本機 Whisper 或自選線上服務。離線辨識選「本機 Whisper」，在同一頁的模型清單按「下載」：會先列出來源、大小與授權，同意後才下載，下載完核對檔案並試跑一次，通過才開始使用。第一次下載模型時會一併下載辨識程式 whisper.cpp（約 9 MB）；它需要的 Microsoft Visual C++ 執行元件由聽字附上，不必另外安裝，舊版下載的辨識程式在下一次辨識時也會自動補上。下載可以取消，再按一次「下載」會從中斷的地方接續。不用的模型可以在同一份清單按「刪除」釋放空間；刪的是正在使用的模型時，會先詢問，並改用另一個已下載的模型。自己放進資料夾的模型不會出現刪除鍵。電腦有 NVIDIA 顯示卡時，同一頁會多一項「顯示卡加速」，下載加速元件（約 685 MB）並試跑成功後就能開啟；顯示卡辨識失敗時，那一句會自動改用 CPU。新版聽字附上更新的辨識程式或顯示卡加速元件時，同一頁會出現「辨識程式有新版本」，按「更新」會先列出來源與大小，同意後下載，並用已下載的模型試跑一次，通過才換成新版；沒通過時繼續使用目前的版本。已下載的模型不用重新下載。
   如果浮條在錄音時間上方提示「通話音質」，辨識可能較不準，可以改用電腦內建或 USB 麥克風。如果同時換了麥克風，兩則提示會一起顯示。說話聲太小時，聽字會在辨識前自動提高音量。

   設定的「語音」頁有「降噪」開關，預設關閉。如果風扇或冷氣的聲音干擾辨識，可以試著開啟。
2. 點一下記事本正文或 Codex 草稿，把游標放在要插字的位置。按錄音快捷鍵開始，再按一次停止；也可點浮窗的圖示。新設定預設為 Ctrl＋Alt＋R，升級沿用使用者的快捷鍵。要換的話，到設定「一般」頁的「錄音快捷鍵」按「變更」，直接按下想用的組合：字母或數字要搭配 Ctrl、Alt 或 Win，F1 到 F24 可以單獨使用（例如 F9），Esc 取消。Ctrl＋Alt＋V 和 Alt＋Shift＋Z 是聽字自己用的鍵，不能選；選的組合被其他程式或 Windows 占用時，設定頁會說明並建議一組可用的。按「停用」可以關閉快捷鍵，只用浮窗的圖示錄音。錄音時浮窗顯示收音音量。
3. 在「辨識完成後」選「自動插入並複製文字」。若游標仍在原記事本正文或 Codex 草稿，文字會插入一次，浮條維持收合，之後按 Ctrl＋V 也能貼上。中途換欄位或無法確認欄位時，文字會放進剪貼簿，同時展開浮窗的編輯區，可以先修改，再自行選地方貼上。
4. 線上辨識失敗時錄音會保留；已配置本機 Whisper 的話，點一下圖示就用同一段錄音改跑本機辨識，也可以按「捨棄這段錄音」。下載的模型放在 `%LOCALAPPDATA%\Tingzi\whisper\downloads`，辨識程式放在 `%LOCALAPPDATA%\Tingzi\whisper` 的 `engine-cpu` 與 `engine-gpu`。自己準備的 `ggml-*.bin` 模型放進同一個 `downloads` 資料夾，也會出現在設定的「本機模型」。舊版以 `TingziFloat/voice-root.txt` 指定的 Whisper 資料夾，升級後仍會沿用。

若每次都想自己按 Ctrl＋V，請選「只複製到剪貼簿」。原本偏好手動檢查文字的人可以沿用「只顯示預覽」。浮條上的「編輯辨識文字」可手動展開結果，剪貼簿忙碌時也能從編輯區取回文字。

**邊講邊出字**　在設定的「語音」頁選擇「Codex 線上辨識」後，可以開啟「邊講邊出字」實驗功能。錄音中每次停頓，剛說完的那一句會經 Codex 傳到 ChatGPT 辨識，辨識好就直接打進錄音開始時游標所在的欄位，例如聊天視窗的輸入框，不必等到停止錄音。

- 錄音途中切換到別的視窗，聽字就不再打字；還沒打進去的句子留在浮條，停止錄音後顯示在預覽並複製到剪貼簿。
- 錄音快捷鍵還按著的時候（「按住說話」），多數程式要等放開才收得到字，這段時間句子先顯示在浮條。想要邊講邊進字，請用按一下開始、再按一下停止的方式。
- 開著「AI 潤稿」，或「辨識完成後」選的不是「自動插入並複製文字」時，句子只顯示在浮條，停止錄音後才依設定處理全文。
- 逐句打進去的文字不會經過 AI 潤稿；個人詞彙與取代規則是一句一句套用的。取消錄音時，已經打進去的句子不會收回。
- 浮條若顯示「停止錄音後會辨識還沒出字的部分」，表示有一句沒辨識成功，聽字會在停止後把剩下的錄音一次辨識完再補上。

**確認這句用了哪個辨識引擎**　辨識進行時，浮條會標示「線上辨識中」或「本機辨識中」。線上失敗、改跑本機時，浮條會顯示本機辨識中。貼入 Codex 草稿時只送出文字，不會附上錄音。

### 按住說話、整理口語與紀錄

- **錄音方式**：設定的「一般」頁可選「按住說話，放開送出」。按著快捷鍵講話，放開就送出；快按一下（不到三分之一秒）則和原本一樣，再按一次才停止。按住說話時，單獨的功能鍵（例如 F9）最好按。
- **整理口語**：預設開啟。去掉句首的「嗯、呃、欸」，把「我我我」「然後然後」這類口吃和重複收成一個，並把子句間的空白與半形標點補成中文標點；有兩個以上子句的句子會補上句號。它只刪這幾類字，不會改寫句子；不需要時可在設定關閉。
- **從改字學詞**：口述把詞寫錯時（例如把「李曉明」寫成「理小名」），切到聽字的注音，在剛插入的文字上把它改對：把錯的詞刪掉或選取起來，打出正確的詞，按 Enter 送出。聽字的注音會記下這個詞換掉了口述的哪一段；兩段讀音相同、寫法不同，聽字就把這個詞記下來，之後的口述遇到同音的字會自動換成它，下一次口述完成時浮條會顯示「已學會」。在其他地方打同音的詞不會被學起來；單一個字也不會學，以免改到太多地方。少數程式不讓輸入法讀取周圍的文字，這時改用最近 10 分鐘內的辨識紀錄比對。這需要開著「注音」頁的本機學習和「隱私」頁的辨識紀錄。為了比對，聽字會把最近 10 分鐘內插入的最多 5 則口述暫存在本機學習資料裡，清除辨識紀錄、關閉辨識紀錄或「從改字學詞」時會一起刪除；聽字不會讀取你在其他程式打的字。學到的詞在「語音」頁的「從改字學詞」按「查看」，刪掉的詞不會再學；也可以整個關閉。清除學習資料時，這份清單會一起清除。
- **辨識紀錄**：預設保留最近 50 則，只存在這台電腦的個人資料夾。浮窗編輯區左下角的「最近紀錄」可以取回任何一則，沒貼上的會標示「未貼上」；按 Alt＋Shift＋Z 會把上一則再貼到目前游標所在的地方。設定的「隱私」頁可以關閉保留或清除全部紀錄。

- **取代規則**：設定的「套用取代規則 → 管理」可以加入「聽到的字 → 要換成的字」，用來修正英文專有名詞的大小寫和固定聽錯的詞，例如把 github 換成 GitHub。英文不分大小寫，而且只比對完整的字；規則存在個人資料夾。
- **依程式設定**：設定的「依程式設定 → 管理」可以替個別程式（以執行檔名稱辨認，例如 `Code.exe`）指定是否整理口語、是否 AI 潤稿、輸出繁體或簡體、辨識完成後怎麼處理、是否去掉句尾的句號，以及 AI 潤稿的輸出語言和「潤稿語氣」。潤稿語氣是給這個程式的額外要求，例如通訊軟體填「口語、輕鬆」，郵件填「正式、有禮貌」，會接在設定頁的「補充說明」後面一起送出。錄音開始時鍵盤在哪個程式，就套用那個程式的規則。
- **AI 潤稿**：選用，預設關閉。在「語音」頁的「AI 潤稿」填入 OpenAI 格式的服務網址、模型名稱與金鑰，按「測試」用一句範例試試，再打開開關。開啟後，辨識出的文字（不是錄音）會連同自訂詞和「補充說明」送到這個服務，整理改口、贅詞、口述的清單與標點；之後才套用自訂詞、從改字學到的詞和取代規則，所以你的寫法不會被改掉。潤稿時浮條顯示「潤稿中」，再點一下取消；服務出錯或逾時時照常插入原文，浮條會說明。去掉空白後不到 8 個字的文字不送出。每次口述完成時，浮條會在訊息後面註明這一句「已潤稿」和花了幾秒，或是沒潤稿的原因，例如「不到 8 個字，未潤稿」。開著「保留最近 50 則辨識紀錄」時，浮窗的「最近紀錄」會在潤稿過的那一則下面多一列「潤稿前」，選它可以取回沒潤稿的文字來比較。潤稿結果如果出現原文沒有的數字，或多了「不」「沒」這類否定的字，聽字會改用原文，以免意思被改反。「輸出語言」選「英文」時，說中文會得到整理好的英文；選「繁體中文」時，說英文會得到中文。金鑰存在 Windows 認證管理員，和辨識服務的金鑰分開；網址是 `localhost`（例如 Ollama）時文字留在這台電腦，可以不填金鑰。
- **用語音改寫選取的文字**：選用，預設關閉，需要先填好上面的 AI 潤稿服務。在「語音」頁打開「用語音改寫選取的文字」後，在任何程式裡選取一段文字，按 Ctrl＋Alt＋E，說出要怎麼改，例如「改得客氣一點」「整理成條列」「翻成英文」，再按一次 Ctrl＋Alt＋E。選取的文字會換成改寫後的結果，剪貼簿也會換回原本的文字。選取的文字和你說的話會送到潤稿服務。沒有選取文字、服務出錯或沒聽到指令時，原文不變。剪貼簿裡原本是圖片等非文字內容時，改寫後不會換回。

### 快捷列

浮窗展開成橫條時，右側設定鍵旁有一個「剪貼簿文字簡繁互轉」鍵。按一下會把剪貼簿裡的文字換成另一種字體：含有簡體字就轉成繁體，否則轉成簡體，浮條會短暫顯示「已轉成繁體」或「已轉成簡體」。剪貼簿沒有可轉換的中文時會顯示「剪貼簿沒有可轉換的文字」。錄音和辨識進行中時這個鍵會暫時隱藏。系統匣選單的「剪貼簿文字簡繁互轉」作用相同。

## 注音與工具

在設定的「注音」頁按「切換到注音輸入法」，或用 Windows＋空白鍵選「聽字・注音與語音輸入法」。注音由聽字內建的引擎處理，不需要其他輸入法，可直接用在記事本、瀏覽器等支援 Windows 文字服務的程式。

打字很快時，聲調鍵比字的最後一個注音早按一點，或一聲字後面沒按空白鍵就接著打下一個字，聽字都會照原本的意思把注音分到正確的字。只有在分法不只一種時（例如 ㄔ 後面直接接 ㄨㄢˇ，可能是「吃晚」也可能是「喘」），會照按鍵的順序合成一個字，這時請在一聲字後面補按空白鍵。

同一個字的注音不必照順序打：聲母、介音、韻母不管先按哪一個，聽字都會排回正確的位置，例如 ㄉ、ㄛ、ㄨ 或 ㄨ、ㄉ、ㄛ 都會組成 ㄉㄨㄛ（多），ㄠ、ㄏ、ˇ 會組成「好」。按錯聲母或韻母時不用先刪除，直接再按正確的那一個就會取代，例如按了 ㄉ 再按 ㄊ 會變成 ㄊ；已經拼成一個字的注音不會被取代，後面的按鍵會當成下一個字。前面的注音本身已經是一個一聲字時（例如 ㄏㄚ「哈」後面補 ㄨ），聽字會先把後面的按鍵當成下一個字的開頭，等這個字打完、確定它們合起來才是一個字時才合回去，例如 ㄨ、ㄉ、ㄛ 要到按下空白鍵或聲調才會變成「多」。如果合起來和分開都各是一個字（例如 ㄛ、ㄉ、ㄨ 可以是「喔督」），聽字會照按鍵的順序分開，這時請照順序打。

照口語或拼音的習慣多打、打錯介音時，聽字會改成標準的拼法：ㄅ、ㄆ、ㄇ、ㄈ 後面的 ㄨㄥ、ㄨㄛ 會去掉 ㄨ，例如 ㄈㄨㄥ 是「風」、ㄅㄨㄛ 是「播」；ㄐ、ㄑ、ㄒ 後面的 ㄨ 會當成 ㄩ，例如 ㄒㄨㄝˊ 是「學」、ㄐㄨㄢˋ 是「眷」；ㄋㄨㄝ、ㄌㄨㄝ 也會當成 ㄋㄩㄝ、ㄌㄩㄝ。多出來的 ㄨ 最後才按也一樣：ㄈ、ㄥ、ㄨ 還是「風」；但如果後面接著打 ㄟˋ 或聲調，ㄨ 就是下一個字的開頭（「風味」「風物」）。其他拼不出字的注音（例如 ㄐ 後面接 ㄜ）會照你打的樣子留在組字區，不會拆成符號和別的字；按了聲調之後接著打的字照常組字，那組注音可以用 Backspace 一次刪掉再重打。

安裝包內含取自 McBopomofo 的公開注音詞庫（MIT 授權，見 `McBopomofo-LICENSE.txt`），新電腦裝好就能打注音；不含語音模型。升級會保留電腦上既有的詞表及語音模型位置，不會被安裝包裡的詞庫覆蓋。學習工具為 `TingziLearning.exe`，支援 `on`、`off`、`status`。

## 注音選項

設定的「注音」頁可調整下列項目，改了就會存下，在重新開啟的應用程式生效：

- **鍵盤配置**：標準（大千）或倚天。
- **整句選字方式**：「整句最佳」比較整句的詞頻總和；「長詞優先」先定案長詞，再由左到右決定其餘的字。兩種的選字結果可能不同，可以依自己的打字習慣挑。
- **候選窗字級**與**大字輸入行**：大字輸入行可關閉。

### 整句選字怎麼決定

每個詞依它本身的常用程度計分，同音字也各自計分。另外，安裝包附一份「哪些詞常接在一起」的統計（`pairs.txt`，約 15 萬組，由中文維基百科的文字統計而來，不含文章內容）：前後兩個詞如果常一起出現，就會優先選它們。這讓長句裡的同音詞比較常選對，例如「程式編輯」不會變成「城市編輯」。統計的來源是百科文章，口語和專業用語涵蓋較少，選錯時用 ↓ 改選，本機學習會記住。

### 自訂詞

按「管理自訂詞」可加入姓名、專有名詞等 2 到 8 個字的詞。輸入詞語後，每個字會帶出詞庫裡的讀音，破音字請從下拉選單選對的讀音。加入的詞在打注音時優先出現，已經開著的程式下一次開始打字就會用到，不必重開；詞存放在 `%LOCALAPPDATA%\Tingzi\user-phrases.txt`，升級與重新安裝都會保留。對話框裡的「匯出」和「匯入」可以把自訂詞帶到另一台電腦。在「語音」頁開啟「套用自訂詞」時，語音辨識結果裡同音的字也會換成這些詞。

### 文字範本

按「文字範本」的「管理」，輸入一個觸發詞（例如「地址」）和要展開的文字。之後打出觸發詞的注音再按 ↓，候選清單裡會出現這段文字；它不會自動取代原本的詞。範本存放在 `%LOCALAPPDATA%\Tingzi\user-templates.txt`。

### 學習資料

「本機學習」用開關啟用或關閉。開啟時會記住你改選過的字，包括句子的第一個字：同樣的前兩個字後面改選同一個字兩次，之後打到這裡就會自動換成它；在任何句子改選過一次的字，下次按 ↓ 時就排在選字清單的最前面，緊接在目前的字後面；之後改選了別的字（包括改回原本的字），就以最後選的為準，前一次當作選錯。在同一句裡連續用選字選出的 2 到 4 個字會先暫記，同樣的詞第二次送出後才列入候選字，偶爾選錯一次不會被學走，已經開著的程式也會馬上用到；設定裡的「已學會的詞」可以查看並刪掉記錯的。開啟本機學習時，也會記住最近 100 句送出的句子（三個字以上），供首碼快打使用；在密碼欄等不適合記錄的地方不會記。設定「隱私」頁的「學習資料」可以帶走或刪除這些紀錄：「匯出」把改字習慣存成 Tab 分隔的文字檔，「匯入」讀回這種檔案，「清除」會全部刪除且無法復原。

## 外觀與啟動

設定的「一般」頁有這三個選項：

- **色系**：跟隨 Windows、淺色或深色。套用到設定、浮條、系統匣選單，以及注音的候選窗與輸入行。選「跟隨 Windows」時，切換系統的深淺色模式後浮條和選單會跟著變；已開著的應用程式裡的候選窗在下次顯示時更新。Windows 開啟高對比時，候選窗與輸入行一律使用系統的高對比色。
- **強調色**：聽字靛色，或跟隨 Windows 的強調色。
- **登入 Windows 時啟動語音浮窗**：開啟後，登入就會在螢幕右側看到聽字圖示。

## 簡體與繁體

在設定的「一般」頁，「輸出文字」可選繁體中文或簡體中文，選了就同時套用到語音辨識結果和注音送出的字。注音組字與候選一律顯示繁體，按 Enter 送出時才依設定轉換。浮條上的簡繁互轉鍵和系統匣選單的「剪貼簿文字簡繁互轉」可把已複製的文字轉成另一種字體。轉換使用 Windows 內建的逐字對照，一個簡體字對應多個繁體字時（例如「发」對應「發」和「髮」）可能需要自己改字。

## 更新

聽字會自動更新。設定「關於」頁的「自動更新」預設開啟：聽字每天最多向 GitHub 查詢一次有沒有新版（開著不關的話也一樣每天查一次），只會送出目前的版本號。找到新版時，聽字會在背景下載安裝程式，並確認檔案沒有損壞，接著跳出視窗詢問「要現在安裝嗎？」。如果正在錄音或辨識，會等你做完才詢問。按「確定」後 Windows 會詢問是否允許變更，按「是」就會開始安裝，畫面只顯示進度。安裝時語音浮窗會先關閉，裝好後自動開啟新版。設定、自訂詞、學習資料與已下載的模型都會保留。按「取消」的話，下次開啟聽字時會再問一次。

不想自動連線時，關掉「自動更新」，聽字就不會自己連到 GitHub。要更新時，到「關於」頁按「立即檢查」，再按「下載並安裝」，會照一般的安裝畫面進行。「這一版改了什麼」可以看更新重點。下載的安裝程式放在 `%LOCALAPPDATA%\Tingzi\updates`，下次更新時舊的會刪掉。新版沒有附安裝程式時，按鈕會改成「開啟下載頁」。

## 回報問題

遇到問題時，到設定的「關於」頁按「回報問題…」，或在系統匣選單按「回報問題…」。聽字會整理出一份內容，包括聽字版本、Windows 版本、你的設定（辨識方式、貼入方式、哪些功能開著），以及最近的操作記錄，例如何時用快捷鍵、浮窗按鈕或選單開始錄音，要貼進哪個程式（只記程式名稱），辨識花了多久，文字有沒有貼進去，哪一步失敗或程式當掉。注音輸入法也會記下在哪個程式啟用、有沒有按鍵沒能交給輸入法而直接打進程式、組字有沒有被程式中斷，兩邊的記錄會依時間排在一起。記錄裡沒有你按了哪些鍵、你說的話或打的字、錄音和金鑰，資料夾路徑裡的使用者名稱也會換掉。

內容會先顯示在視窗裡，可以直接刪改。按「到 GitHub 回報」會複製內容，並在瀏覽器開啟已經填好版本與記錄的回報頁，請補上發生了什麼事、怎麼操作的，再按送出；回報會公開在 GitHub 上，需要 GitHub 帳號。沒有帳號的話，按「存成檔案」再寄給別人幫忙，或按「複製」貼到別處。

操作記錄存在 `%LOCALAPPDATA%\Tingzi\tingzi-log.txt`，注音輸入法的在同一個資料夾的 `tingzi-ime-log.txt`，只在這台電腦上；各自超過 256 KB 會改名成 `.old.txt` 再開新檔，所以合計最多約 1 MB。想清掉的話，結束聽字後刪除這幾個檔即可。安裝失敗時的記錄另外寫在 `%TEMP%` 裡名為「Setup Log <日期>」的文字檔。

## 回復與移除

程式安裝於 `%ProgramFiles%\Tingzi\v0.10.0`（語音浮窗是其中 `TingziFloat` 資料夾裡的 `TingziFloat.exe`），使用者設定與學習資料在 `%LOCALAPPDATA%\Tingzi`。移除方式見[安裝及第一次使用](#安裝及第一次使用)；選擇保留個人資料時，這些資料會留在 `%LOCALAPPDATA%\Tingzi`，本機詞表與語音資料夾的位置設定也會另存到 `kept-after-uninstall`，供日後重新安裝使用。解除安裝會清理安裝目錄根層中可確認屬於聽字的項目；其他或無法確認歸屬的根層項目會保留，但根層中與聽字程式檔同名的檔案也會清除。經確認的聽字版本資料夾（例如 `v0.10.0`）會整個刪除，包括自行放在裡面的檔案；若要保留，請先備份並移到 `%ProgramFiles%\Tingzi` 之外，保留個人資料的選擇不會保留這些檔案。若輸入法檔案仍被其他程式使用，安裝程式會先嘗試改名再安排於重新啟動後刪除；若檔案無法改名，就會保留而不安排刪除。必要時請重新啟動 Windows 完成已排程檔案的清除。

第三方元件的授權與聲明見 `THIRD-PARTY-NOTICES.txt`。發行包內的 `release-manifest.json` 列出每個發行檔案的雜湊。
