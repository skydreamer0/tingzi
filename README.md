# 聽字｜Tingzi

**說完就能打，錯字用注音改。**

聽字・注音與語音輸入法是 Windows 上的繁體中文輸入工具。把游標放在記事本、瀏覽器或其他文字欄位，說完一句就會插入文字；遇到同音字，直接用注音重新選字。

Traditional Chinese voice and Zhuyin input for Windows.

[Windows 使用手冊](windows/README.md) · [回報問題](https://github.com/skydreamer0/tingzi/issues) · [參與開發](CONTRIBUTING.md)

## 功能

- **語音輸入**：螢幕右側常駐一顆麥克風，點一下開始、再點一下停止。辨識完成時，若游標還在原欄位，文字只插入一次，同時複製到剪貼簿。
- **換欄也不會貼錯**：錄音途中換了欄位，文字會留在浮窗預覽，讓你自己決定貼到哪裡。
- **注音修字**：用 Win＋空白鍵切到「聽字・注音與語音輸入法」，在要改的位置打注音選字。
- **簡體／繁體輸出**：在設定選「輸出文字」，語音結果和注音送出的字都會照選擇轉換；系統匣選單也能把剪貼簿的文字轉成繁體或簡體。
- **跟著系統的外觀**：設定、浮條、系統匣選單、注音候選窗和輸入行會跟隨 Windows 的深色或淺色模式，也可以固定其中一種；強調色可用聽字靛色或 Windows 的強調色。
- **內建注音引擎**：使用自己的注音引擎與公開授權詞庫，不需要另外安裝其他輸入法。支援標準（大千）與倚天兩種鍵盤配置。
- **自訂詞**：在設定加入姓名或專有名詞，打注音時優先出現；破音字可以指定讀音。
- **本機或線上辨識**：可選本機 Whisper，或透過第三方 `codex-asr` 使用線上辨識。浮條會標示每一句實際用了哪個引擎。

## 語音浮條怎麼看

![語音浮條的組成與五種狀態](docs/images/voice-bar.svg)

- **平常**：浮條收合成螢幕右側的一顆麥克風，不擋畫面。上下拖曳可以換位置。
- **錄音**：點麥克風或按快捷鍵開始，浮條顯示收音音量；再點一次停止。
- **辨識**：浮條標示這一句正在用線上還是本機引擎。
- **完成**：游標還在原欄位時，文字插入一次並複製到剪貼簿，浮條維持收合。
- **換了欄位或辨識失敗**：浮條展開，顯示文字或原因。文字已在剪貼簿，自己按 Ctrl＋V 貼到想要的地方；線上失敗時可以用同一段錄音改跑本機辨識。

在麥克風上按右鍵可以開啟設定，或顯示完整浮條。

## 用注音改字

1. 把游標放到要改的位置，按 **Win＋空白鍵** 選「聽字・注音與語音輸入法」。
2. 用標準注音鍵盤打出讀音，例如「ㄋㄧˇ」。組字中的文字會顯示在游標旁的輸入行。
3. 按 **↓** 開啟候選，用數字鍵或方向鍵選字；候選超過一頁時用 PgUp／PgDn 或空白鍵換頁。
4. 按 **Enter** 送出，按 **Esc** 取消。

連續打多個音節時，聽字會先組成整句，再讓你逐段改字。組字時一律顯示繁體；設定為簡體輸出時，按 Enter 送出的文字才轉成簡體。開啟「本機學習」後，同一個前文下改選過的字會優先出現；學習資料只存在自己的電腦。

## 目前狀態

主分支為 **0.6.4 開發版**，尚未發布安裝包。要試用請依[開發指南](docs/development/README.md)自行建置。接下來要補齊的項目列在[一般用戶體驗規格](docs/specs/general-user-experience.md)。

## 安裝（自行建置的套件）

1. 準備 x64 Windows 10/11，以及 [.NET 8 Desktop Runtime（x64）](https://dotnet.microsoft.com/download/dotnet/8.0)。
2. 完整解壓縮套件，以系統管理員身分執行 `InstallTingzi.cmd`。
3. 開始功能表搜尋 **聽字**，開啟設定，在「語音輸入」選麥克風和辨識方式。

移除時以系統管理員身分執行安裝目錄裡的 `RemoveTingzi.cmd`。詳細步驟見 [Windows 使用手冊](windows/README.md)。

## 第一次輸入

1. 點一下記事本正文，把游標放在要插字的地方。
2. 點右側麥克風，或按 **Ctrl＋Alt＋R** 開始說話；再按一次停止。
3. 文字會插入游標位置。要改同音字，按 **Win＋空白鍵** 選「聽字・注音與語音輸入法」，打注音重新選字。

**錄音會送去哪裡？** 選「本機 Whisper」時在自己的電腦辨識，工具與模型須自行配置。選「線上辨識」時，`codex-asr` 會把該段錄音送往 ChatGPT 辨識，需要有效的登入。
