# 聽字・注音與語音輸入法 0.6.2｜Windows

## 安裝及第一次使用

需要 x64 Windows 與 Microsoft .NET 8 Desktop Runtime（x64）。解壓縮整份 ZIP，在解壓縮目錄以系統管理員身分執行 `InstallTingzi.cmd`。安裝完成後，按 Windows 鍵搜尋「聽字」，即可在同一個視窗開啟「語音輸入」與「注音與工具」。

升級會沿用同一個 Windows 輸入法、偏好設定、錄音快捷鍵與本機詞表。若先前的浮窗還在執行，請先完成錄音、保留待用的預覽；下次正常登入 Windows 時會使用新版。Windows 的輸入法清單可用 Win＋空白鍵開啟，名稱為「聽字・注音與語音輸入法」。

## 找回浮窗

平常啟動時，螢幕工作區最右側只顯示麥克風。先點一下要輸入文字的欄位，再點右側麥克風開始講；圖示變成停止鍵時再點一次結束。辨識完成且已在原欄位插入時，右側維持小圖示。換欄位或遇到辨識錯誤時，浮窗會展開，顯示結果或原因。

上下拖曳麥克風可調整位置。要看完整裝置、辨識來源或改偏好，在圖示上按右鍵開設定或選「顯示完整浮條」。在完整浮條上按右鍵選「靠右收合為麥克風」可回到螢幕邊緣。

在**開始功能表搜尋「語音浮窗」**，或在系統匣圖示上按右鍵選「顯示／找回浮窗」。待命時浮條顯示在滑鼠所在的螢幕。按浮條右側的設定鍵可在原位展開「語音輸入」與「注音與工具」。按「返回浮條」或 Esc 可關閉設定，儲存變更請按「儲存設定」。

## 語音輸入

1. 在「語音輸入」選擇麥克風和辨識方式。線上辨識使用隨附的第三方 codex-asr，將該次錄音交給 ChatGPT 做辨識，需要可用的 Codex 登入。離線辨識需要自行配置 Whisper 工具和模型。
2. 點一下記事本正文或 Codex 草稿，把游標放在要插字的位置。按錄音快捷鍵開始，再按一次停止；也可點浮窗的麥克風。新設定預設為 Ctrl＋Alt＋R，升級沿用使用者的快捷鍵。浮窗顯示麥克風與收音音量。
3. 在「辨識完成後」選「自動插入並複製文字」。若游標仍在原記事本正文或 Codex 草稿，文字會插入一次，浮條維持收合，之後按 Ctrl＋V 也能貼上。中途換欄位或無法確認欄位時，文字會放進剪貼簿，同時展開浮窗預覽，讓你自行選地方貼上。
4. 線上失敗時，可將同一段錄音改用本機辨識。選擇本機模式前，先確認設定頁顯示 Whisper 和模型已就緒。已有 `TingziFloat/voice-root.txt` 的使用者升級會沿用該檔。自行配置時，檔案內容為本機資料目錄的完整路徑，其中須有 `whisper-v1.9.2/Release/whisper-cli.exe` 及 `downloads/ggml-base.bin`。

若每次都想自己按 Ctrl＋V，請選「只複製到剪貼簿」。原本偏好手動檢查文字的人可以沿用「只顯示預覽」。浮條上的箭頭可手動展開結果，剪貼簿忙碌時也能從預覽取回文字。

**確認這句用了哪個辨識引擎**　待命時，浮條標出下次使用的引擎。完成後，浮條上的「來源」會顯示這句實際使用的「Codex 線上」或「本機 Whisper」。線上失敗、手動改跑本機後，這段結果的來源會改成 Whisper。Codex 只接收貼進草稿的文字，助理不會在聊天裡新增語音附件。

## 注音與工具

在設定的「注音與工具」頁按「切換到注音輸入法」，或用 Win＋空白鍵選「聽字・注音與語音輸入法」。注音由聽字內建的引擎處理，不需要其他輸入法。按「開啟本機打字板」可在獨立欄位練習；注音也可直接用在其他支援 Windows 文字服務的程式。

安裝包內含取自 McBopomofo 的公開注音詞庫（MIT 授權，見 `McBopomofo-LICENSE.txt`），新電腦裝好就能打注音；不含語音模型。升級會保留電腦上既有的詞表及語音模型位置，不會被安裝包裡的詞庫覆蓋。學習工具為 `TingziLearning.exe`，支援 `on`、`off`、`status`。

## 外觀與啟動

設定的「外觀與啟動」頁有三個選項：

- **色系**：跟隨 Windows、淺色或深色。套用到設定、浮條、系統匣選單，以及注音的候選窗與輸入行。選「跟隨 Windows」時，切換系統的深淺色模式後浮條和選單會跟著變；已開著的應用程式裡的候選窗在下次顯示時更新。Windows 開啟高對比時，候選窗與輸入行一律使用系統的高對比色。
- **強調色**：聽字靛色，或跟隨 Windows 的強調色。
- **登入 Windows 時啟動語音浮窗**：勾選後，登入就會在螢幕右側看到麥克風。

## 簡體與繁體

在設定的「語音輸入」頁，「輸出文字」可選繁體中文或簡體中文，儲存後同時套用到語音辨識結果和注音送出的字。注音組字與候選一律顯示繁體，按 Enter 送出時才依設定轉換。系統匣選單的「剪貼簿文字轉成繁體／簡體」可轉換已複製的文字。轉換使用 Windows 內建的逐字對照，一個簡體字對應多個繁體字時（例如「发」對應「發」和「髮」）可能需要自己改字。

## 回復與移除

程式安裝於 `%ProgramFiles%\Tingzi\v0.6.2`，使用者設定與學習資料在 `%LOCALAPPDATA%\Tingzi`。移除使用 `RemoveTingzi.cmd`；本機詞表、語音模型位置與使用者資料會保留，供日後重新安裝使用。

第三方元件的授權與聲明見 `THIRD-PARTY-NOTICES.txt`。發行包內的 `release-manifest.json` 列出每個發行檔案的雜湊。
