# 聽字・注音與語音輸入法 0.7.7｜Windows

## 安裝及第一次使用

需要 x64 Windows。下載 `Tingzi-Setup-<版本>-x64.exe`，雙擊後依畫面安裝；安裝程式會要求系統管理員權限。語音浮窗使用 Microsoft Edge WebView2 Runtime，Windows 11 已內建，大多數 Windows 10 電腦也已經有；沒有的話，安裝程式會自動從微軟下載安裝；網路連不上時聽字照樣裝好，注音可以先用。不必再安裝 .NET。安裝程式也會把聽字加進你的鍵盤清單（缺少「中文（台灣）」時一併加入），裝好後按 Windows＋空白鍵就能選到；同一台電腦的其他使用者第一次開啟語音浮窗時，也會自動加入。萬一清單裡沒有，到「設定 → 時間與語言 → 語言與地區」，在「中文（台灣）」的「語言選項」按「新增鍵盤」選「聽字・注音與語音輸入法」，或在系統匣選單按「切換到注音輸入法」。安裝記錄寫在 `%TEMP%` 裡名為「Setup Log <日期>」的文字檔，裝不起來時可以附上這個檔回報問題。

要在多台電腦上不經畫面安裝（例如由管理員派送），在系統管理員的命令提示字元執行 `Tingzi-Setup-<版本>-x64.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART`。結束碼 0 表示成功；其他數字表示沒有裝好，原因寫在 `/LOG="路徑"` 指定的記錄檔。

已經裝過聽字時，執行新版的安裝程式就是升級；同一版再執行一次會重新安裝，修復被改動或損壞的程式檔。開著的語音浮窗會先關閉，裝好後自動開啟新版。要移除時，到「設定 → 應用程式 → 已安裝的應用程式」找「聽字・注音與語音輸入法」，按「解除安裝」；過程中會詢問是否一併刪除個人資料（偏好、自訂詞、學習資料、辨識紀錄與已下載的模型），預設保留。保留時，程式目錄裡的本機詞表與 `voice-root.txt` 會另外複製到 `%LOCALAPPDATA%\Tingzi\kept-after-uninstall`。

也可以用 ZIP 安裝：解壓縮整份 ZIP，在解壓縮目錄以系統管理員身分執行 `InstallTingzi.cmd`，移除時執行安裝目錄裡的 `RemoveTingzi.cmd`。這種方式不會出現在應用程式清單。安裝完成後，按 Windows 鍵搜尋「聽字」，即可在同一個視窗開啟「語音輸入」與「注音與工具」。

第一次在這台電腦開啟時，設定視窗會帶你走三個步驟：選麥克風並測試收音、選辨識方式（選本機時直接下載建議的模型），以及在記事本裡口述一句、用注音改一個字。每一步都可以略過；之後想重來，到設定的「關於」頁按「首次設定」。從舊版升級的人不會看到這些步驟。

升級會沿用同一個 Windows 輸入法、偏好設定、錄音快捷鍵、自訂詞、文字範本、學習資料與本機詞表。從 0.7.0 起，語音浮窗改為新的程式，安裝位置、名稱與開始功能表捷徑都不變；升級後若收音的麥克風不對，請到設定重新選一次。若先前的浮窗還在執行，請先完成錄音、保留待用的預覽；下次正常登入 Windows 時會使用新版。Windows 的輸入法清單可用 Win＋空白鍵開啟，名稱為「聽字・注音與語音輸入法」。

## 找回浮窗

平常啟動時，螢幕工作區最右側只顯示聽字圖示（橫耳鍵標誌）。先點一下要輸入文字的欄位，再點右側的圖示開始講；圖示變成停止鍵時再點一次結束。辨識完成且已在原欄位插入時，右側維持小圖示。換欄位或遇到辨識錯誤時，浮窗會展開，顯示結果或原因；沒有插入的文字會出現在浮窗裡可以修改的編輯區。

上下拖曳圖示可調整位置。在圖示上按右鍵會展開完整浮條；按浮條右側的「收合到螢幕右側」可回到螢幕邊緣。

在**開始功能表搜尋「語音浮窗」**，或在系統匣圖示上按右鍵選「顯示／找回浮窗」。待命時浮條顯示在滑鼠所在的螢幕。按浮條右側的設定鍵，或在系統匣選單選「開啟設定…」，會開啟設定視窗，共有「一般」、「語音」、「注音」、「隱私」和「關於」五頁。在「語音」頁的麥克風旁按「測試」，對著麥克風說話時下方的音量條會跟著動，十秒後自動停止。設定左側是分頁導覽，每個設定項目旁有一句說明。每項設定改了就立刻套用，不需要另外儲存；按「關閉」或 Esc 可關閉設定。

## 語音輸入

1. 在設定的「語音」頁選擇麥克風和辨識方式。線上辨識（Codex）已內建在程式裡，不再是另一個 `codex-asr.exe`；它使用第三方的 codex-asr 元件，將該次錄音交給 ChatGPT 做辨識，需要這台電腦上可用的 Codex 登入。離線辨識選「本機 Whisper」，在同一頁的模型清單按「下載」：會先列出來源、大小與授權，同意後才下載，下載完核對檔案並試跑一次，通過才開始使用。第一次下載模型時會一併下載辨識程式 whisper.cpp（約 9 MB）。下載可以取消，再按一次「下載」會從中斷的地方接續。不用的模型可以在同一份清單按「刪除」釋放空間；刪的是正在使用的模型時，會先詢問，並改用另一個已下載的模型。自己放進資料夾的模型不會出現刪除鍵。電腦有 NVIDIA 顯示卡時，同一頁會多一項「顯示卡加速」，下載加速元件（約 685 MB）並試跑成功後就能開啟；顯示卡辨識失敗時，那一句會自動改用 CPU。
2. 點一下記事本正文或 Codex 草稿，把游標放在要插字的位置。按錄音快捷鍵開始，再按一次停止；也可點浮窗的圖示。新設定預設為 Ctrl＋Alt＋R，升級沿用使用者的快捷鍵。要換的話，到設定「一般」頁的「錄音快捷鍵」按「變更」，直接按下想用的組合：字母或數字要搭配 Ctrl、Alt 或 Win，F1 到 F24 可以單獨使用（例如 F9），Esc 取消。Ctrl＋Alt＋V 和 Alt＋Shift＋Z 是聽字自己用的鍵，不能選；選的組合被其他程式或 Windows 占用時，設定頁會說明並建議一組可用的。按「停用」可以關閉快捷鍵，只用浮窗的圖示錄音。錄音時浮窗顯示收音音量。
3. 在「辨識完成後」選「自動插入並複製文字」。若游標仍在原記事本正文或 Codex 草稿，文字會插入一次，浮條維持收合，之後按 Ctrl＋V 也能貼上。中途換欄位或無法確認欄位時，文字會放進剪貼簿，同時展開浮窗的編輯區，可以先修改，再自行選地方貼上。
4. 線上辨識失敗時錄音會保留；已配置本機 Whisper 的話，點一下圖示就用同一段錄音改跑本機辨識，也可以按「捨棄這段錄音」。下載的模型放在 `%LOCALAPPDATA%\Tingzi\whisper\downloads`，辨識程式放在 `%LOCALAPPDATA%\Tingzi\whisper` 的 `engine-cpu` 與 `engine-gpu`。自己準備的 `ggml-*.bin` 模型放進同一個 `downloads` 資料夾，也會出現在設定的「本機模型」。已有 `TingziFloat/voice-root.txt` 的使用者升級後照舊可用：該檔指向的資料夾裡的 `whisper-v1.9.2/Release/whisper-cli.exe` 與 `downloads` 內的模型仍會被找到。

若每次都想自己按 Ctrl＋V，請選「只複製到剪貼簿」。原本偏好手動檢查文字的人可以沿用「只顯示預覽」。浮條上的「編輯辨識文字」可手動展開結果，剪貼簿忙碌時也能從編輯區取回文字。

**確認這句用了哪個辨識引擎**　辨識進行時，浮條會標示「線上辨識中」或「本機辨識中」。線上失敗、改跑本機時，浮條會顯示本機辨識中。Codex 只接收貼進草稿的文字，助理不會在聊天裡新增語音附件。

### 按住說話、整理口語與紀錄

- **錄音方式**：設定的「一般」頁可選「按住說話，放開送出」。按著快捷鍵講話，放開就送出；快按一下（不到三分之一秒）則和原本一樣，再按一次才停止。按住說話時，單獨的功能鍵（例如 F9）最好按。
- **整理口語**：預設開啟。去掉句首的「嗯、呃、欸」，把「我我我」「然後然後」這類口吃和重複收成一個，並把子句間的空白與半形標點補成中文標點；有兩個以上子句的句子會補上句號。它只刪這幾類字，不會改寫句子；不需要時可在設定關閉。
- **從改字學詞**：口述把詞寫錯時（例如把「李曉明」寫成「理小名」），切到聽字的注音，逐字選字把它改對。下一次開始錄音時，聽字會比對最近的辨識紀錄和注音新學到的詞：同一組讀音、寫法不同，就把這個詞記下來，之後的口述遇到同音的字會自動換成它，完成時浮條會顯示「已學會」。這需要開著「注音」頁的本機學習和「隱私」頁的辨識紀錄；聽字不會讀取你在其他程式打的字。學到的詞在「語音」頁的「從改字學詞」按「查看」，刪掉的詞不會再學；也可以整個關閉。清除學習資料時，這份清單會一起清除。
- **辨識紀錄**：預設保留最近 50 則，只存在這台電腦的個人資料夾。浮窗編輯區左下角的「最近紀錄」可以取回任何一則，沒貼上的會標示「未貼上」；按 Alt＋Shift＋Z 會把上一則再貼到目前游標所在的地方。設定的「隱私」頁可以關閉保留或清除全部紀錄。

- **取代規則**：設定的「套用取代規則 → 管理」可以加入「聽到的字 → 要換成的字」，用來修正英文專有名詞的大小寫和固定聽錯的詞，例如把 github 換成 GitHub。英文不分大小寫，而且只比對完整的字；規則存在個人資料夾。
- **依程式設定**：設定的「依程式設定 → 管理」可以替個別程式（以執行檔名稱辨認，例如 `Code.exe`）指定是否整理口語、是否 AI 潤稿、輸出繁體或簡體、辨識完成後怎麼處理，以及是否去掉句尾的句號。錄音開始時鍵盤在哪個程式，就套用那個程式的規則。
- **AI 潤稿**：選用，預設關閉。在「語音」頁的「AI 潤稿」填入 OpenAI 格式的服務網址、模型名稱與金鑰，按「測試」用一句範例試試，再打開開關。開啟後，辨識出的文字（不是錄音）會連同自訂詞和「補充說明」送到這個服務，整理改口、贅詞、口述的清單與標點；之後才套用自訂詞、從改字學到的詞和取代規則，所以你的寫法不會被改掉。潤稿時浮條顯示「潤稿中」，再點一下取消；服務出錯或逾時時照常插入原文，浮條會說明。去掉空白後不到 8 個字的文字不送出。每次口述完成時，浮條會在訊息後面註明這一句「已潤稿」和花了幾秒，或是沒潤稿的原因，例如「不到 8 個字，未潤稿」。開著「保留最近 50 則辨識紀錄」時，浮窗的「最近紀錄」會在潤稿過的那一則下面多一列「潤稿前」，選它可以取回沒潤稿的文字來比較。金鑰存在 Windows 認證管理員，和辨識服務的金鑰分開；網址是 `localhost`（例如 Ollama）時文字留在這台電腦，可以不填金鑰。

### 快捷列

浮窗展開成橫條時，右側設定鍵旁有一個「剪貼簿文字簡繁互轉」鍵。按一下會把剪貼簿裡的文字換成另一種字體：含有簡體字就轉成繁體，否則轉成簡體，浮條會短暫顯示「已轉成繁體」或「已轉成簡體」。剪貼簿沒有可轉換的中文時會顯示「剪貼簿沒有可轉換的文字」。錄音和辨識進行中時這個鍵會暫時隱藏。系統匣選單的「剪貼簿文字簡繁互轉」作用相同。

## 注音與工具

在設定的「注音」頁按「切換到注音輸入法」，或用 Win＋空白鍵選「聽字・注音與語音輸入法」。注音由聽字內建的引擎處理，不需要其他輸入法，可直接用在記事本、瀏覽器等支援 Windows 文字服務的程式。

安裝包內含取自 McBopomofo 的公開注音詞庫（MIT 授權，見 `McBopomofo-LICENSE.txt`），新電腦裝好就能打注音；不含語音模型。升級會保留電腦上既有的詞表及語音模型位置，不會被安裝包裡的詞庫覆蓋。學習工具為 `TingziLearning.exe`，支援 `on`、`off`、`status`。

## 注音選項

設定的「注音」頁可調整下列項目，改了就會存下，在重新開啟的應用程式生效：

- **鍵盤配置**：標準（大千）或倚天。
- **整句選字方式**：「整句最佳」比較整句的詞頻總和；「長詞優先」先定案長詞，再由左到右決定其餘的字。兩種的選字結果可能不同，可以依自己的打字習慣挑。
- **候選窗字級**與**大字輸入行**：大字輸入行可關閉。

### 整句選字怎麼決定

每個詞依它本身的常用程度計分，同音字也各自計分。另外，安裝包附一份「哪些詞常接在一起」的統計（`pairs.txt`，約 15 萬組，由中文維基百科的文字統計而來，不含文章內容）：前後兩個詞如果常一起出現，就會優先選它們。這讓長句裡的同音詞比較常選對，例如「程式編輯」不會變成「城市編輯」。統計的來源是百科文章，口語和專業用語涵蓋較少，選錯時用 ↓ 改選，本機學習會記住。

### 自訂詞

按「管理自訂詞」可加入姓名、專有名詞等 2 到 8 個字的詞。輸入詞語後，每個字會帶出詞庫裡的讀音，破音字請從下拉選單選對的讀音。加入的詞在打注音時優先出現，存放在 `%LOCALAPPDATA%\Tingzi\user-phrases.txt`，升級與重新安裝都會保留。對話框裡的「匯出」和「匯入」可以把自訂詞帶到另一台電腦。在「語音」頁開啟「套用自訂詞」時，語音辨識結果裡同音的字也會換成這些詞。

### 文字範本

按「文字範本」的「管理」，輸入一個觸發詞（例如「地址」）和要展開的文字。之後打出觸發詞的注音再按 ↓，候選清單裡會出現這段文字；它不會自動取代原本的詞。範本存放在 `%LOCALAPPDATA%\Tingzi\user-templates.txt`。

### 學習資料

「本機學習」用開關啟用或關閉。開啟時會記住你改選過的字，包括句子的第一個字；在同一句裡連續用選字選出的 2 到 4 個字，送出一次就會記成新詞；設定裡的「已學會的詞」可以查看並刪掉記錯的。開啟本機學習時，也會記住最近 100 句送出的句子（三個字以上），供首碼快打使用；在密碼欄等不適合記錄的地方不會記。設定「隱私」頁的「學習資料」可以帶走或刪除這些紀錄：「匯出」把改字習慣存成 Tab 分隔的文字檔，「匯入」讀回這種檔案，「清除」會全部刪除且無法復原。

## 外觀與啟動

設定的「一般」頁有這三個選項：

- **色系**：跟隨 Windows、淺色或深色。套用到設定、浮條、系統匣選單，以及注音的候選窗與輸入行。選「跟隨 Windows」時，切換系統的深淺色模式後浮條和選單會跟著變；已開著的應用程式裡的候選窗在下次顯示時更新。Windows 開啟高對比時，候選窗與輸入行一律使用系統的高對比色。
- **強調色**：聽字靛色，或跟隨 Windows 的強調色。
- **登入 Windows 時啟動語音浮窗**：開啟後，登入就會在螢幕右側看到聽字圖示。

## 簡體與繁體

在設定的「一般」頁，「輸出文字」可選繁體中文或簡體中文，選了就同時套用到語音辨識結果和注音送出的字。注音組字與候選一律顯示繁體，按 Enter 送出時才依設定轉換。浮條上的簡繁互轉鍵和系統匣選單的「剪貼簿文字簡繁互轉」可把已複製的文字轉成另一種字體。轉換使用 Windows 內建的逐字對照，一個簡體字對應多個繁體字時（例如「发」對應「發」和「髮」）可能需要自己改字。

## 更新

設定的「關於」頁的「更新」區會顯示目前版本與有沒有新版。「每天自動檢查新版」預設開啟：聽字每天最多向 GitHub 查詢一次，只會送出目前的版本號；找到新版時，浮窗會短暫提示一次。關閉這個開關後，聽字不會自動連線，要更新時按「立即檢查」。

有新版時，按「這一版改了什麼」可以看更新重點，按「下載並安裝」會下載安裝程式、核對檔案沒有損壞後開啟它。依畫面完成安裝即可；安裝時語音浮窗會先關閉，完成後自動開啟新版。設定、自訂詞、學習資料與已下載的模型都會保留。下載的安裝程式放在 `%LOCALAPPDATA%\Tingzi\updates`，下一次更新時會刪掉舊的。新版沒有附安裝程式時，按鈕會改成「開啟下載頁」。

## 回復與移除

程式安裝於 `%ProgramFiles%\Tingzi\v0.7.7`（語音浮窗是其中 `TingziFloat` 資料夾裡的 `TingziFloat.exe`），使用者設定與學習資料在 `%LOCALAPPDATA%\Tingzi`。移除使用 `RemoveTingzi.cmd`；本機詞表、語音模型位置與使用者資料會保留，供日後重新安裝使用。

第三方元件的授權與聲明見 `THIRD-PARTY-NOTICES.txt`。發行包內的 `release-manifest.json` 列出每個發行檔案的雜湊。
