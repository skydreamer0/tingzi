聽字

語音輸入

麥克風

語音輸入使用的收音裝置。

測試收音

按「測試」後對著麥克風說話，音量條會跟著動，十秒後自動停止。

辨識

同時套用到語音結果與注音送出的字，逐字轉換。

把辨識結果裡同音的字換成你加入的自訂詞，例如人名和專有名詞。

去掉句首的「嗯、呃、欸」、重複的「我我我」「然後然後」，並把空白與半形標點補成中文標點。不會改寫你的句子。

錄音途中若切換到別的視窗，辨識文字會留在浮窗預覽，不會貼錯地方。

操作

錄音快捷鍵

按一次開始錄音，再按一次停止。

「按住說話」時按著快捷鍵講，放開就送出；快按一下則和原本一樣，再按一次才停止。

只存在這台電腦。沒貼上的文字可以從浮窗的紀錄取回，或按 Alt+Shift+Z 再貼一次上一則。

浮窗裡辨識文字的大小。

注音與工具

打字

注音符號在鍵盤上的排法。

「整句最佳」比較整句的詞頻總和；「長詞優先」先定案長詞，再由左到右決定其餘的字。

打字時在游標旁放大顯示正在組的字。

以上四項在按下「儲存設定」後，於重新開啟的應用程式生效。

打字時的按鍵

Shift 加 ， 。 ？ ！ 等鍵輸入全形標點，[ ] 輸入「」，` 開啟符號表。組字時按 Tab 把第一個詞切短，選字時按 Tab 切換近音字。Shift＋Enter 送出並把這段字存成自訂詞。

詞語與學習

自訂詞

加入姓名、專有名詞等詞語，打注音時優先出現。

文字範本

打出觸發詞的注音後按 ↓，從候選清單選出整段文字，例如地址或常用回覆。

讀取學習狀態中…

學習資料

匯出成文字檔帶到另一台電腦再匯入，或全部清除。

工具

切換到注音輸入法

切換後，在原本的應用程式內打字。

本機打字板

開啟獨立欄位練習注音與選字。

Windows 語言與鍵盤設定

管理 Windows 的鍵盤清單和輸入語言。

外觀與啟動

外觀

套用到設定、浮窗，以及注音的候選窗與輸入行。

按鈕與選取項目使用的顏色。

啟動

登入後就會在螢幕右側看到聽字圖示。

變更在按下「儲存設定」後生效。

關於

聽字・注音與語音輸入法

Windows 的繁體中文注音與語音輸入。注音組字、學習資料、自訂詞和本機語音辨識都在這台電腦上處理；只有選用線上辨識時，音檔才會送到第三方服務。
