# 聽字｜Tingzi

**說完就能打，錯字用注音改。**

聽字・注音與語音輸入法是 Windows 上的繁體中文輸入工具。把游標放在記事本、瀏覽器或其他文字欄位，說完一句就會插入文字；遇到同音字，直接用注音重新選字。

Traditional Chinese voice and Zhuyin input for Windows.

[Windows 使用手冊](windows/README.md) · [macOS 說明（準備中）](macos/README.md) · [回報問題](https://github.com/skydreamer0/tingzi/issues) · [參與開發](CONTRIBUTING.md)

## 功能

- **語音輸入**：螢幕邊緣常駐一顆聽字圖示（橫耳鍵標誌，可拖到左側或右側），點一下開始、再點一下停止。辨識完成時，若游標還在原欄位，文字只插入一次，同時複製到剪貼簿。
- **按住說話**：可以改成按著快捷鍵講話、放開就送出；快按一下則和原本一樣，再按一次才停止。
- **換欄也不會貼錯**：錄音途中換了欄位，文字會留在浮窗裡可以修改的編輯區，讓你自己決定貼到哪裡。
- **整理口語與取代規則**：自動去掉句首的「嗯、呃」和口吃重複，補上中文標點，不會改寫句子；固定聽錯的詞或英文專有名詞的大小寫，可以用「聽到的字 → 要換成的字」的規則修正。
- **AI 潤稿（選用）**：預設關閉。開啟後，辨識出的文字會交給你自己填的 OpenAI 格式服務，整理改口、贅詞、口述的清單和標點，之後才套用你的自訂詞與取代規則；服務出錯時照常插入原文。
- **辨識紀錄**：最近 50 則辨識結果只存在自己的電腦，可以從浮窗取回任何一則；按 Alt＋Shift＋Z 把上一則再貼一次。
- **依程式設定**：可以替個別程式指定輸出繁體或簡體、是否整理口語、是否 AI 潤稿，以及辨識完成後怎麼處理。
- **注音修字**：用 Win＋空白鍵切到「聽字・注音與語音輸入法」，在要改的位置打注音選字。
- **簡體／繁體輸出**：在設定選「輸出文字」，語音結果和注音送出的字都會照選擇轉換；浮條上的簡繁互轉鍵和系統匣選單也能把剪貼簿的文字在繁體和簡體之間互轉。
- **跟著系統的外觀**：設定、浮條、系統匣選單、注音候選窗和輸入行會跟隨 Windows 的深色或淺色模式，也可以固定其中一種；強調色可用聽字靛色或 Windows 的強調色。
- **內建注音引擎**：使用自己的注音引擎與公開授權詞庫，不需要另外安裝其他輸入法。支援標準（大千）與倚天兩種鍵盤配置。
- **自訂詞**：在設定加入姓名或專有名詞，打注音時優先出現，語音辨識的同音字也會換成這些詞；破音字可以指定讀音。
- **從改字學詞**：口述寫錯的詞，用注音逐字選對一次，之後的口述遇到同音的字就會自動寫成這個詞。學到的詞只存在自己的電腦，可以在設定查看和刪除。
- **整句選字**：依每個字詞的常用程度和「哪些詞常接在一起」的統計選字，長句裡的同音詞比較常選對，例如「程式編輯」不會變成「城市編輯」。
- **標點、符號表與文字範本**：Shift 加標點鍵輸入全形標點，`` ` `` 開啟分類的符號表，Shift＋空白鍵切換全形英數；常用的地址或回覆可以存成範本，從候選清單選出。
- **改字更快**：組字時用 ← → 把游標移到句子中間，只改那一個字；按 Tab 強制斷詞，選字時按 Tab 看近音字。連續選出的字會自動記成新詞，Ctrl 加數字鍵可以把游標前的幾個字存成自訂詞。
- **首碼快打**：只打每個字的第一個注音再按空白鍵，就能選出之前打過的整句（需開啟本機學習）。
- **設定改了就套用**：設定分成「一般」、「語音」、「注音」、「隱私」和「關於」五頁，每一項改了立刻生效，不需要另外儲存。
- **三種辨識方式**：本機 Whisper（模型在設定頁一鍵下載，含針對台灣口音與中英夾雜的 Breeze ASR 25；有 NVIDIA 顯示卡可以下載加速元件）、自選線上服務（OpenAI 格式的轉寫服務，例如 OpenAI、Groq 或自己電腦上的 Whisper 服務，自備金鑰），或程式內建的 Codex 線上辨識。自選服務會一併送出你的自訂詞，幫忙認出人名和專有名詞。辨識時浮條會標示這一句用的是線上還是本機。

## 語音浮條怎麼看

![語音浮條的組成、換了欄位時的編輯卡與六種狀態](docs/images/voice-bar.svg)

- **平常**：浮條收合成螢幕邊緣的一顆橫耳鍵，不擋畫面。按住拖曳可以換位置，放開會貼到較近的左側或右側。
- **錄音**：點圖示或按快捷鍵開始，鍵帽旁長出一條膠囊顯示錄音時間，鍵帽裡的直筆隨音量起伏；再點一次停止。
- **辨識**：浮條標示這一句正在用線上還是本機引擎。
- **潤稿**：開啟 AI 潤稿時，辨識完會多一步，浮條顯示「潤稿中」；再點一下取消，這一句就不插入。潤稿失敗時照常插入原文，完成訊息會說明原因。
- **完成**：游標還在原欄位時，文字插入一次並複製到剪貼簿；膠囊顯示這句話幾秒，再縮回鍵帽。
- **換了欄位或辨識失敗**：膠囊留著，顯示文字或原因。換了欄位時，文字會出現在膠囊旁的編輯卡，也已在剪貼簿，自己按 Ctrl＋V 貼到想要的地方；線上辨識失敗時錄音會保留，已配置本機 Whisper 的話，點一下圖示就改用本機辨識。

在圖示上按右鍵可以展開膠囊；滑鼠移到膠囊上會出現簡繁互轉、設定與收合鍵，設定也可以從系統匣選單開啟。

## 用注音改字

1. 把游標放到要改的位置，按 **Win＋空白鍵** 選「聽字・注音與語音輸入法」。
2. 用標準注音鍵盤打出讀音，例如「ㄋㄧˇ」。組字中的文字會顯示在游標旁的輸入行。
3. 按 **↓** 開啟候選，用數字鍵或方向鍵選字；候選超過一頁時用 PgUp／PgDn 或空白鍵換頁。
4. 按 **Enter** 送出，按 **Esc** 取消。

連續打多個音節時，聽字會先組成整句，再讓你逐段改字。組字時一律顯示繁體；設定為簡體輸出時，按 Enter 送出的文字才轉成簡體。開啟「本機學習」後，同一個前文下改選過的字會優先出現；學習資料只存在自己的電腦。

## 目前狀態

最新版本是 **0.7.7**，安裝包在 [Releases](https://github.com/skydreamer0/tingzi/releases) 下載。這是預覽版：安裝包沒有數位簽章，Windows 可能會跳出警告。要自己建置請看[開發指南](docs/development/README.md)。macOS 版（只有語音輸入，沒有注音輸入法）正在準備，還沒有發行，進度見 [macOS 說明](macos/README.md)。接下來要補齊的項目列在[一般用戶體驗規格](docs/specs/general-user-experience.md)。

## 安裝

1. 準備 x64 Windows 10/11。語音浮窗需要 Microsoft Edge WebView2 Runtime；Windows 11 已內建，大多數 Windows 10 電腦也已經有，不必另外安裝 .NET。
2. 從 Releases 下載 `Tingzi-<版本>-windows-x64.zip`，完整解壓縮，以系統管理員身分執行 `InstallTingzi.cmd`。
3. 開始功能表搜尋 **聽字**，開啟設定，在「語音」頁選麥克風和辨識方式。

移除時以系統管理員身分執行安裝目錄裡的 `RemoveTingzi.cmd`。詳細步驟見 [Windows 使用手冊](windows/README.md)。

## 第一次輸入

1. 點一下記事本正文，把游標放在要插字的地方。
2. 點螢幕邊緣的聽字圖示，或按 **Ctrl＋Alt＋R** 開始說話；再按一次停止。在設定的「一般」頁選了「按住說話，放開送出」的話，按著快捷鍵講完放開即可。
3. 文字會插入游標位置。要改同音字，按 **Win＋空白鍵** 選「聽字・注音與語音輸入法」，打注音重新選字。

**錄音會送去哪裡？** 選「本機 Whisper」時在自己的電腦辨識；模型和辨識程式在設定的「語音」頁下載，下載前會列出來源、大小與授權，下載後核對檔案並試跑過才使用。選「自選線上服務」時，錄音和自訂詞會送到你填的服務網址，費用依該服務計算；金鑰存在 Windows 認證管理員，不寫進設定檔。網址是 `localhost` 時錄音留在自己的電腦。選「Codex 線上辨識」時，程式內建的 Codex 辨識會把該段錄音送往 ChatGPT 辨識，需要這台電腦上有效的 Codex 登入。開啟「AI 潤稿」時，辨識出的文字（不是錄音）會連同自訂詞和你寫的補充說明送到你填的潤稿服務，網址是 `localhost` 時文字留在自己的電腦；沒開啟時不會送出。
